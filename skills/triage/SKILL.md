# Constellation Triage

## Purpose

Write issue-ready recommendations for follow-up work. Triage does not implement or maintain a parallel backlog. Persist future work in the issue tracker or workflow-local recommendation text.

## Use When

- Cartographer finds out-of-scope mismatch.
- Reviewer finds out-of-scope test/doc/contract gaps.
- Conductor finds future work during planning.
- Implementation exposes deferred debt.
- The user wants issue-ready text.

## Classify

Use one or more: bug, cleanup, missing test, missing doc, missing architecture packet, architecture weakness, feature, tooling, unresolved decision, research hardening, dependency cleanup, security/privacy, performance/resource.

## Issue Authority

Ground rules govern direct issue creation. If unclear, produce recommendations and ask.

## Questions

What is this? How important? Who owns it? Current scope or future work? What evidence supports it? What makes it done? What is out of scope?
