# Glossary

The project's controlled vocabulary — the source of truth for *one name for one thing*
(constellation-how-to-talk, rule 2). Consult it before naming a concept in prose; add a
row when you coin one.

| Term | Short | Definition | Instead of |
|---|---|---|---|
| <Canonical Name> | <ABBR or —> | <One line; says what it *is*.> | ~~<variant>~~ — use **<Canonical Name>** |
| Task | — | One bounded unit of work owned by a single agent. | ~~job~~, ~~worker~~ — use **Task** |
| Launch Order | LO | The frozen brief an Admiral hands a Commander to run one issue. | ~~handoff doc~~ — use **Launch Order** |

## Fields

- **Term** — the full canonical name; the one true name for the concept.
- **Short** — its accepted abbreviation or acronym, or `—` when it has none. Term and
  Short together are the expansion; no separate field restates it.
- **Definition** — one line, grounded. Says what the thing *is*, not what it is
  "responsible for."
- **Instead of** — variants a reader might meet elsewhere, each written as a redirect:
  *not this → use **Term***. This column is one-way. It exists to retire a variant, never
  to offer a synonym the writer can rotate through — a term with an *Instead of* entry has
  exactly one accepted form, and it is the Term.
- *Example* (optional) — one real sentence using the term correctly, added only where a
  definition needs grounding.
