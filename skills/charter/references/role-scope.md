# Charter Role Scope

Charter compiles project doctrine into role-operable context. It does not run Pilot gates, curate architecture, execute Crew work, or redesign the Constellation role topology.

## Adjacent Roles

| Role | What they do | Charter duty |
|---|---|---|
| Pilot | Pilot owns gated workflow control, scope, evidence integration, Crew dispatch, and semantic closeout. | Give Pilot and Cartographer Orchestrator context with planning/framing, gating/evidence, authority/scope, repo action authority, and stop/ask consequences. |
| Cartographer | Cartographer owns current-only structural truth: architecture packets, index, overlays, map build, and drift checks. | Give Pilot and Cartographer Orchestrator context that states architecture and scope constraints clearly enough to request or perform map verification. |
| Crew | Crew executes bounded implementation and review from a handoff. Crew does not infer hidden intent, route work, create issues, or close gates. | Give Crew Crew context with implementation, verification, review/blocking, and stop/report rules. Handoff-only details stay out of durable Crew context. |

## Compile Rule

Project invariants may appear in both Orchestrator and Crew context, but must use role-specific wording. Orchestrator context guides Pilot/Cartographer decisions. Crew context guides implementer/reviewer behavior.
