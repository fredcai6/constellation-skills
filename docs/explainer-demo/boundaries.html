Boundaries & Dependencies

The load-bearing rules and relationships that hold the system together, sourced from overlays/constraints.yml and overlays/purposes.yml.

Cross-region constraints (the dependency rules)

Each constraint governs the subsystems listed under it — e.g. which region a package may not import. These are the boundaries the architecture enforces.

Analysis reads from DB only; no direct FastF1 calls (constraint:db_only_data_access)

FastF1 is the live upstream source; the DB is the canonical truth. Keeping all analysis code DB-only ensures reproducibility and prevents analysis from depending on FastF1 availability or rate limits.

src/latent_power must not import src/evo_predictor (constraint:latent_power_no_evo_import)

latent_power owns only the domain-independent solver lifecycle so it can be reused for any pairwise-ranking domain without pulling in F1-specific dependencies. F1-specific feature construction, compound normalization, and adapter wiring stay in evo_predictor.

struct:latent_power
Same-season full-year compound priors rejected by default in eval/predict (constraint:time_safe_compound_prior)

Full-year same-season artifacts include future races relative to the eval target, leaking race outcomes into backtests. Cross-season artifacts are the safe proxy. Same-season use during training is a marked bootstrap compromise, not the eval or prediction default.

struct:compound_priorstruct:evo.data_adapter
Circuit config requires exact year; no silent fallback to prior year (constraint:exact_year_circuit_lookup)

Circuit characteristics (layout, surface, DRS zones) can change year-to-year. Silent fallback would use stale config and produce incorrect features without any error signal.

struct:evo.data_adapter
Fused latent field is the canonical pipeline object; per-module outputs are diagnostics (constraint:fused_fields_canonical)

Carrying per-module predictions as the canonical output conflates the diagnostic view (how did each module perform?) with the prediction (what is our best estimate?). Field-level Bayesian fusion over event-local latent fields is the composition primitive. Generic fusion math belongs in latent_power; F1 orchestration belongs in evo_predictor/fusion.py.

struct:evo
Physics-region packages must not import evo-region packages (constraint:physics_region_no_evo_import)

src/physics/ and src/preprocessing/ (the trajectory/ estimator) are physics-region. They must not import src/evo_predictor/, src/latent_power/, or src/compound_prior/. This keeps the physics estimator stack independent of the prediction pipeline so it can be developed, tested, and replaced without evo coupling. Enforced by src/preprocessing/trajectory/__init__.py docstring and the physics-primary direction spec (2026-06-10).
