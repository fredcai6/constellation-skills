Detail (from the Cartographer packet)

Responsibility

Bridge-only layer. Parses and validates evo sampled-runtime outputs, converts them into the v2 ClassificationFutureSet wire contract, and re-exports the report generator from src/fantasy_scoring/. Contains no scoring, optimization, or beam-search logic — all of that lives in src/fantasy_scoring/.

Key Modules

sampled_runtime_bridge.py Parses evo sampled-runtime JSON blobs. Validates the payload and extracts a NormalizedFinalOrderSampleSet for a specific race. Entry point for consuming sampled-runtime outputs upstream of fantasy evaluation.

sample_futures.py Converts a NormalizedFinalOrderSampleSet into a v2 ClassificationFutureSet of integer driver-index permutations. Bridges the sampled-runtime representation into the classification-futures contract consumed by src/fantasy_scoring/.

classification_futures.py v2 wire contract. Validates classification-futures payloads and provides the ClassificationFutureSet dataclass. Consumed by both sample_futures.py and src/fantasy_scoring/.

sampled_runtime_report.py Thin re-export shim: from src.fantasy_scoring.artifacts import generate_report. No logic of its own.

scoring.py Thin re-export shim: from src.fantasy_scoring.scoring_rules import ScoringCalculator. A façade so callers (e.g. src/reporting/race_report/) can reach the scorer through src.strategy without importing fantasy_scoring directly.

Known Limits

  • This package is intentionally thin; it owns only the parse/validate/convert pipeline from sampled-runtime JSON to ClassificationFutureSet
  • All scoring, optimization, beam search, and report building logic is in src/fantasy_scoring/
