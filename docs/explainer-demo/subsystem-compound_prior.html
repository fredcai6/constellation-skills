Detail (from the Cartographer packet)

Responsibility

Infer tire-wear effects from race observations. Produce compact runtime prior artifacts consumed by the evo pipeline during feature construction. The canonical goal is one package-level: infer per-compound beta (intercept) and gamma (wear slope) parameters from observed lap times.

Canonical Execution Path

1. extract_race_observations  →  raw segment observations (DB → parquet/CSV)
2. fit_race_baseline          →  race-progress baseline (optional standalone)
3. fit_tire_wear_model        →  alternating baseline + compound model
4. write_tire_wear_run_bundle →  full run bundle (run_summary.json, compound_parameters.json, parquets)
5. promote_runtime_artifact   →  compact runtime prior artifact (compound_prior_summary.json per season)
6. runtime_normalization      →  CompoundNormalizer (consumed by evo data_adapter)

CLI entry points are in scripts/ (not inside this package). Python API entry: fit_tire_wear_model(obs_df, ...).

Key Modules

extractor.py Extracts raw race-segment observations from the SQLite DB. One observation row per driver/lap/segment. Applies cleanliness filtering (VSC, safety car, pit laps). Computes cumulative race progress. Outputs a DataFrame with compound_absolute (C1–C6), laps_on_tire, segment_time_s, race_progress, cleanliness tier flags, and gap-proximity columns.

baseline.py — Race Progress Baseline Constrained parametric fit: segment_time = alpha(race, driver, segment) + beta(race, segment) * race_progress. Per-race/segment slope (beta_segment) pooled toward a global slope. All slopes constrained to be strictly negative. Multi-race pooling occurs in the tire-wear model, not here. Standalone use for debug inspection only.

solver/ — Alternating Tire-Wear Solver (package) Split across _core.py, _iterate.py, _ridge.py, _solve.py. Alternates: fit pooled race baseline → stack residuals → fit compound model → repeat. Compound model: absolute C-number identities (C1–C6), per-compound beta (intercept) + gamma (wear slope). Identifiability: weighted sum-zero constraint on intercepts. Non-dimensional normalization: residuals converted to fractional pace before compound fitting, making gamma invariant to sector duration. Optional features: burn-in/tail windowing, residual outlier filtering (MAD-based), race delta gamma block, effective-age modifiers (VSC, close-ahead, close-behind), sparse-prior mode. Physics constraints: gamma non-negative, adjacent C-number slopes monotone.

runtime_normalization.py — CompoundNormalizer Loads a compound_prior_summary.json artifact for a given target year. Applies time-safety rule: selects the latest artifact from a source season strictly before target year; rejects same-season full-year artifacts by default. normalize_lap_time(observed_time, compound, tire_age, baseline_time) adjusts to equivalent C3 at age zero. Emits support counts, DQI factor, warnings, and artifact metadata for downstream diagnostics.

baseline_schema.py, observation_schema.py Schema validation for baseline fit results and observation DataFrames.

identifiability.py Sum-zero constraint enforcement, identifiability diagnostics, and compound support checks.

cleanliness.py Lap/segment cleanliness classification into tiers (A, B, C) based on VSC flags, gap proximity, and pit-lap proximity.

gap_calculator.py Gap-to-car-ahead and gap-to-car-behind from race-lap data.

gamma_modifier.py Race-delta gamma modifier; fits per-race additive offset on compound wear slope.

diagnostics/ (package) Identification diagnostics: compound_identifiability.csv, compound_slope_sensitivity.csv, pit_window_reset_checks.csv. Split across _tables.py, _plots_basic.py, _plots_solver.py, _tire_wear_plots.py, _tire_wear_io.py. Plotting helpers; not on the live prediction path.

rolling_prior.py Rolling compound prior construction (sub-season windowed builds).

neural_rate.py Experimental neural wear-rate module. Not on the canonical path.

Scripts

scripts/fit_compound_prior.py — exploratory/debug only. Fits compound prior from pre-baselined observations. Not the canonical production path.

scripts/build_pooled_compound_prior.py — builds pooled multi-season gold compound_prior artifacts for target years (#410). Pools all baselined parquets from seasons strictly before the target year (ONLY consumes observations from seasons < Y — time-safe by construction). Writes params/gold/compound_prior/{Y}/compound_prior_summary.json with artifact_id = "pooled-compound-prior-{max_season}-for-{Y}". Replaces the per-season fit_compound_prior path for identifying the β ladder; multi-season pooling is required because the per-season β is degenerate (§7.7). The 2023/2024/2025 gold artifacts in params/gold/compound_prior/ were regenerated via this path (#410); the 2022 artifact predates #410 and uses the old per-season path. Schema unchanged; CompoundNormalizer interface unchanged.

scripts/build_rolling_compound_priors.py — builds rolling per-round compound prior artifacts for a target year (historical full seasons + completed target-year rounds 1..N-1, with sigmoid-downweighted historical observations via rolling_prior.scale_historical_observations). Output under outputs/rolling_compound_priors/{target_year}/before_r{N:02d}/. Parallelizable across rounds via src.utils.utilization (UTILIZATION_LEVELS, resolve_resource_plan, run_jobs) with its own --utilization flag (#356); result-preserving (input-order reassembly, 1-worker in-process short-circuit).

scripts/diagnose_compound_beta_degeneracy.py / scripts/diagnose_compound_gamma_identifiability.py — read-only diagnosis harnesses (#382, exploratory; DB-only, self-contained). Rebuild the crossover gate's pooled fixed-effects design from the per-season DBs and read the committed gold artifacts to measure WHY the per-season gold β is degenerate (identification/pooling-limited — ridge refuted) and to quantify γ identifiability (collinearity/VIF vs the fuel-evolution term, per-γ SE, profile likelihood). Not on any prediction path; write evidence under their run package. Findings recorded in docs/evo/prediction_ceiling_and_priorities.md §7.7.

Empirical Degradation Sensor (#443)

empirical_sensor.py — Empirical compound-degradation sensor productionized from the FINDINGS.md survey (git dfd8862a). Reads car telemetry from TelemetryStore (2022+ race sessions) and lap metadata from per-year DBs (f1_data_*.db via raw sqlite3, annotated as deliberate — DatabaseManager does not support cross-year multi-session batch queries). Implements the validated production recipe:

  • Feature extraction: per-lap contrast = log(corner_q15 / DRS-off-straight-mean) from car speed/throttle/drs streams; lap_time_s from TelemetryStore laps; per-lap coast-fraction filter.
  • Per-(race, compound) OLS slope cells: b_lat (lateral contrast vs tyre age), b_lap (lap time vs tyre age = target), b_long (longitudinal, 0.0 when absent), EB-shrunk race-demeaned target y.
  • Relative-rank encoding: compound rank within race (1=hardest).
  • Circuit-compound LOO prior (cc_prior): leave-one-race-out mean of demeaned slope.
  • Eight-feature ridge model: {relrank, cc_prior, lat, long0, lat_era, lat_deg, long_era, lat_absc}.
  • Validated: LOO pairwise P = 0.8032 on 77 races (2022–2024; 2025 EB tau2=0 — noise > signal); permutation z = +5.22σ; ladder monotone-up.

Public API: EmpiricalDegModel dataclass, load_race_laps(), build_degradation_cells(), fit_empirical_model(), predict_compound_degradation().

Known Limits

  • Compound model uses absolute C-numbers (C1–C6); no SOFT/MEDIUM/HARD fallback in runtime path
  • Same-season full-year artifacts rejected by default (time-safety; see constraint:time_safe_compound_prior in docs/architecture/overlays/constraints.yml, formerly ADR 0002)
  • Race-start adapter does not model VSC restarts or anomalies
  • Neural wear-rate module (neural_rate.py) is exploratory, not on canonical path
  • Gold artifacts for 2023/2024/2025 in params/gold/compound_prior/ were regenerated as pooled multi-season fits via build_pooled_compound_prior.py (#410); the 2022 artifact predates #410 and was produced via the old per-season fit_compound_prior path. Full historical regen (2018–2026 unified solver) remains a Triage item.
  • Per-season β degeneracy (#382): the gold per-season fits cannot identify the fresh-pace β ladder — 8/8 seasons are non-monotone even at ridge=0; the ordered ~0.7%/step ladder only emerges when seasons are pooled (the build_rolling_compound_priors.py direction). β degeneracy is identification/pooling-limited, not a ridge or solver bug (measured; docs/evo/prediction_ceiling_and_priorities.md §7.7). The race-side γ-up degradation ladder is confounded (not just under-identified) and is not recoverable from race-lap data without a de-confounding design.
