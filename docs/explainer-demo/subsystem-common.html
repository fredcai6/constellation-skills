Packet: src/common — Shared Utilities

status: currentlevel: containersrc/common/confidence: highstruct:common

Detail (from the Cartographer packet)

Responsibility

Domain-independent shared utilities. Currently contains distribution utilities used across the data and evo domains.

Key Modules

distribution_utils.py Statistical distribution helpers. Used by latent_power and evo_predictor for uncertainty propagation and sampling operations.

student_t.py Domain-independent Student-t helpers and the shared DEFAULT_NU_LOSS constant / FormulaRule type. Imported by latent_power (config.py), evo_predictor (module_training_orchestration.py), and calibration, which is why latent_power and evo carry a depends-on edge to common.

pairwise_ordering.py (#443) Neutral within-race pairwise-ordering accuracy metric. pairwise_ordering_accuracy(cells_df, predicted, truth_col, weight_col, race_col) → float computes the weighted fraction of correctly-ordered compound pairs pooled across races (P=1.0 perfect, P=0.5 random). Weights by min(lap_count_a, lap_count_b). Pure numpy/pandas, no domain imports. Usable by both Evo (compound_prior.empirical_sensor) and Physics-W3 without creating a physics→evo import — satisfying constraint:physics_region_no_evo_import.

Notes

  • Small domain-independent package; all three modules are active
  • May grow if more cross-domain utilities are needed
