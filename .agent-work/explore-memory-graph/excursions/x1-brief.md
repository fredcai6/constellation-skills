# Excursion Brief: Organizing forms beyond the graph

Cycle 2 (shotgun), `explore-memory-graph`. Human-initiated.

## The one named question

What ways and tools have people used to organize large bodies of diverse, interconnected thoughts — and do any of them rest on a form that is genuinely NOT a graph (or that a plain node-and-edge graph fails to capture)?

Context for the searcher: the project is designing an agent memory system whose inspiration sits somewhere between a mind map and Wikipedia — a typed, weighted knowledge graph. Before hardening that, we want the widest honest survey of alternative forms. "It's secretly a graph too" is an acceptable per-item verdict, but say what the graph framing LOSES about it (spatial position, hierarchy discipline, linearity, faceted dimensions, continuous space, etc.).

## Type

research

**Why this type:** prior art / survey question — facts about existing tools and traditions, answerable from the web and literature.

## What "answered" looks like

A cited survey of 10–20 distinct organizing forms, each with: (1) what it is and a canonical tool/tradition using it (e.g. Zettelkasten, wikis, outliners, spatial canvases, commonplace books, memory palaces, faceted classification / library science, ontologies, hypertext research systems, databases/spreadsheets, embedding/latent spaces — go beyond this starter list); (2) whether it reduces to a graph, and if so what the reduction loses; (3) the one idea the memory-graph design should steal or explicitly decline. End with a shortlist: the 3–5 forms that most challenge or enrich the node-and-edge assumption.

## Budget / stop conditions

- Budget: one focused research pass (web search + what you already know), report even if partial. Aim for breadth over depth.
- Do NOT design the memory system; do NOT evaluate against this repo's code. Survey only.
- **Scoped nulls:** if you find no genuinely non-graph form, that verdict is scoped: state what traditions you searched and which you did NOT. It never closes the question of graph-sufficiency itself.

## Research excursion

- **Sources:** web (tools for thought / PKM literature, HCI and hypertext research, library & information science, knowledge-representation literature). Prefer primary or canonical descriptions over listicles.
- **Findings format:** each claim carries its source (URL or named work). Contradictions surfaced, not smoothed.
