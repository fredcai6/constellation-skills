Detail (from the Cartographer packet)

Responsibility

All fantasy scoring, lineup evaluation, optimization, and beam-search logic. Consumes ClassificationFutureSet payloads (from src/strategy/) and produces scored lineups, score distributions, and beam-search reports. Also owns the report-building artifacts that read from the sampled-runtime bridge.

Scoring Model

Base score: Delta-sum — sum of |predicted_position - actual_position| for selected picks (lower is better). Bingo bonus: Progressive bonus for exact position matches (-1 for first exact, -2 for second, etc.).

Key Modules

scoring_rules.py ScoringCalculator: implements delta-sum plus progressive bingo bonus scoring. Also exports fantasy_score_from_predictions as a convenience entry point.

lineup_evaluator.py Core lineup scoring against futures:

  • score_lineup_against_future — score one lineup against one future
  • score_lineup_against_futures — score one lineup across a ClassificationFutureSet; returns FantasyScoreDistribution
  • Baseline lineup generators: expected_finish_order_lineup, assignment_lineup_with_metadata, greedy_abs_error_lineup

expected_assignment.py MILP-based exact top-k assignment optimizer. Finds the optimal fantasy lineup over a scenario distribution.

  • optimize_fantasy_order_from_scenarios — scenario-set optimizer
  • optimize_fantasy_order_from_latent — Student-t parametric optimizer (per-driver n_eff)
  • FantasyOptimizationResult — result container
  • sample_pl_scenarios_from_latent — scenario sampling from per-driver Student-t predictive (predictive_t seam)
  • dqi_to_n_eff — documented DQI → effective-sample-size mapping for the sampler

beam_search.py Multi-objective beam search over a ClassificationFutureSet. Runs four objective lanes in parallel: mean score, risk-adjusted score, balanced score, and max-score. Returns FantasyBeamSearchResult.

  • beam_search_lineups — main entry point

stats.py percentile_linear utility for score-distribution summarization.

artifacts.py Beam-search report builders. generate_report reads from src/strategy/classification_futures and src/strategy/sampled_runtime_bridge and assembles the full strategy report output.

season.py Season-level fantasy aggregation primitives (consumed by the evo walkforward/ 2025 backtest, #439). extract_top10_picks parses a predictions payload; RaceResult/SeasonResult carry per-race and per-season scores; SeasonAggregator.aggregate folds per-race results into a season total via ScoringCalculator. Intra-package only (imports scoring_rules); the cross-region consumer is src/evo_predictor/walkforward/.

Known Limits

  • Fantasy scoring is a custom game format (not standard Fantasy F1 platform)
  • MILP optimizer in expected_assignment.py requires a compatible solver (e.g., CBC via PuLP); not tractable for very large pick sets
  • Beam search objective lanes are fixed at four; lane weights are not tunable at runtime
