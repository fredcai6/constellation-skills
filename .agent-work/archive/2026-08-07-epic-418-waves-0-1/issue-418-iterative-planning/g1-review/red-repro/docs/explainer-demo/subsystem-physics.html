Detail (from the Cartographer packet)

Responsibility

Vehicle-dynamics parameter measurement from telemetry: classify a lap into regimes, fit per-channel force/grip parameters with honest covariance, expose a per-car capability API, simulate ideal laps from fitted parameters, and (Epic 2) fit those parameters per session and pool them across a constructor's sessions.

Physics is upstream-fed, prediction-isolated: it consumes the windowless trajectory estimate from src/preprocessing/trajectory/ (position + velocity + acceleration + covariance) and raw quali telemetry from the durable telemetry store (src/data/telemetry_store.py, DB-first) or — as a fallback — the FastF1 cache through the single preprocessing loader seam; it imports no fastf1 itself (#503), and no evo-region package (evo_predictor, latent_power, compound_prior) — see constraint:physics_region_no_evo_import. There is no data flow from physics estimates back into the prediction pipeline today: nothing outside src/physics/ imports it.

The container holds three layers plus support:

  • Layer 1 — per-lap force-channel fitting (parameter_estimator.py and the per-channel fits): telemetry regimes → longitudinal/lateral/braking/traction parameters with covariance.
  • Capability API (capability.py, capability_envelope.py): the per-car pace/capability facade and the anisotropic gg-v envelope the simulator reads.
  • struct:physics.layer2 — the cross-session frontier-view estimator (#496) and Layer-A pooling (#492); see its node below.
  • Per-session fit store + evidence (session_fit.py, fit_store.py, fit_batch.py, fit_evidence.py, sim_evaluator.py): Epic 2 P0/P1 — fit one quali session, persist FitRecords to a standalone SQLite store, and report identifiability/pooling feasibility.
  • struct:physics.utilization — the C1 driver-utilization layer (#510); see its node below.

Truth-Anchored Test Levels

Physics tests use four evidence levels (L1–L4 as defined in CREW_CONTEXT and GLOSSARY):

  • L1: analytical / closed-form reference
  • L2: invariant or known-answer physical behavior
  • L3: limit / degenerate-case reduction
  • L4: independent benchmark parity

Any new or modified physics model requires test evidence at the highest applicable level.
