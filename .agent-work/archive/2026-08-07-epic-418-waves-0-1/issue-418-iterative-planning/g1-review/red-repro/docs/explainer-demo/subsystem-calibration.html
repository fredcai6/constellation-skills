Detail (from the Cartographer packet)

Responsibility

Scores how well-calibrated the trained latent-power predictive distributions are, and arbitrates the per-task Student-t tail rule on held-out evidence. Owns the distribution-agnostic calibration scorers (PIT, coverage, CRPS), the per-task dual-reference baseline, and the Phase 4 tail-rule sweep harness.

Does not own training, the loss objective, or the gold cycle — it is a diagnostic/arbitration layer that reads trained gold-cycle bundles and evaluates their distributions. Belongs to the Evo verification region (its dependency profile is squarely evo).

Key Modules

scoring.py — Pure Calibration Scorers Distribution-agnostic scoring functions: pit_values, interval_coverage, coverage_curve, crps_gaussian, mean_crps_gaussian, crps_from_samples, and summarize_calibration → CalibrationSummary. Operates on any object exposing .cdf(x) / .interval(level).

baseline.py — Per-Task Calibration Baseline TaskCalibration, evaluate_task_calibration, r_over_sigma_quantiles. Scores a task's predictions under the current Gaussian assumption against a dual reference.

harness.py — Live Baseline Harness Wires the dual-reference calibration to trained bundles: discovers the latest gold-cycle bundle, extracts per-task (mu, sigma, target_mu) by running torch inference over eval-year DB batches, and builds/writes the baseline report.

sweep.py — Phase 4 Tail-Rule Sweep Arbitrates the Student-t tail rule (ν) per task on evidence, reusing the per-task arrays the harness extracts.

run.py / __main__.py — CLI py -m src.calibration — runs the baseline + sweep harness. Caches extracted per-task arrays to .npz so the baseline and sweep share a single (slow) torch extraction pass.
