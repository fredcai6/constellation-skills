Detail (from the Cartographer packet)

Responsibility

Generic latent-field solving. Owns: validated pair batches, pairwise neural network, pairwise training loss, field solving, module lifecycle, bundle payloads, and module diagnostics. Does not own F1-specific database loading, race-weekend feature construction, or compound-prior preprocessing. Those live in src/evo_predictor.

Boundary rule (constraint:latent_power_no_evo_import, see docs/architecture/overlays/constraints.yml): src/latent_power must not import src/evo_predictor. F1-specific adapter code stays on the evo side; this package is reusable for any pairwise-ranking domain. (Originally ADR 0001; that ADR was folded into the constraint overlay.)

Key Modules

modules.py — Module Registry Central registry for all latent-power modules. get_module(name) performs name lookup and fails fast on unknown or duplicate names. Modules are registered by name string; the registry is the only valid entry point for module instantiation.

network.py — Pairwise Neural Network Inner network that produces pairwise means and uncertainty for each directed entity pair. Takes a PairBatch tensor as input; outputs pairwise delta distributions. Architecture and hidden dimension controlled by training config.

training.py — Training Loop Full training loop: forward pass, retro-delta Student-t NLL on the mean head, optional detached sigma Student-t NLL (term B, ν from student_t_nu_sigma when set), symmetry regularizer, backward pass, validation split, early stopping. Full-eval validation emits uncertainty_diagnostics with r_over_sigma_p50/p90/p95/p99 and sigma_mean into module_diagnostics.json and gold-report rows (#304). Called by evo adapter training harness but contains no F1-specific logic.

field_solve.py — Field Solve Generalized-least-squares field solve over event-local entities (solve(pairwise, pair_index, n_entities, config) -> FieldSolution). Given pairwise means mu and sigmas from the network, it builds a design matrix A (P,N) with weights W = 1/σ² and solves the ridge-regularized normal equations (AᵀWA + λI) π = AᵀW·mu (torch.linalg.solve); solve_sigma_floor clamps σ before forming W (conditioning guard). Gauge: median-zero on π (removes the translation invariance of the latent field — only power differences are identifiable). Posterior covariance is M⁻¹ with the gauge direction zeroed; pairwise variance is cov[i,i]+cov[j,j]−2·cov[i,j], the input to rank-distribution sampling. Disconnected pair graphs are detected by union-find and handled per disconnected_graph_policy (fail or per_component). Stateless per event; no persistent season recursion. (This contract supersedes the retired docs/evo/BT_FIELD_SOLVER_SPEC.md, whose BCE-likelihood/graph-Laplacian description predates the GLS-on-(mu,σ) solve and retro-delta supervision.)

losses.py — Pairwise Losses Retro-delta Student-t NLL (mean head), detached sigma Student-t NLL (term B), symmetry regularizer, output magnitude regularizer. BCE and triangle losses were removed; gold training is retro-delta only.

models.py — Data Models PairBatch: validated tensor container for pairwise input features (entity pairs, labels, feature matrix). ModuleFieldResult: field solution + uncertainty output. PriorState: neutral per-event prior. Other internal model types.

pair_index.py Directed-pair indexing utilities for building PairBatch objects.

config.py Training config dataclass. Controls network architecture, optimizer, learning rate, regularizer weights, early stopping patience and min delta, student_t_nu (term A), optional student_t_nu_sigma (term B override), and lambda_sigma_nll.

exceptions.py Module-local exception types.

alignment_report.py Diagnostic alignment report between predictive and retroactive field solutions.

preprocessor_contract.py Protocol for preprocessor objects that transform raw feature rows into PairBatch-compatible tensors.

retro_*.py — Retroactive Supervision Implements retroactive truth supervision (ADR 0008 — student-t NLL). Files:

  • retro_observation.py — retroactive label types
  • retro_loader.py — loads retro truth from DB artifacts
  • retro_delta_join.py — joins predictive and retro solutions
  • retro_solve.py — retro solve pass
  • retro_modules.py — retro-capable module wrappers
  • retro_comparable.py — comparability checks
  • retro_solution.py — retro solution container
  • retro_tau.py — tau scale estimation
  • pairwise_retro_bridge.py — bridge between pairwise and retro paths

rank_metrics.py Ranking evaluation metrics. Computes rank_mae_vs_retro_bt (vs the reconstructed BT order) and, given optional actual_positions, rank_mae_vs_actual (vs the real finishing/quali/start order) for the schema-v6 gold metrics.

rank_chance.py Blind-chance reference for the rank metrics: expected_random_rank_mae(n) = (n²−1)/(3n), the expected MAE of a uniform random permutation of a field of size n. Supplies the per-event floor used to express rank MAE as skill.

nll_eval.py Student-t pairwise NLL evaluation (pairwise_nll) and the median-relative nll_skill (floor − raw, in nats). The skill value is the cross-module-comparable, scale-robust signal consumed by fusion covariance weighting.

start_only_baseline.py Baseline that predicts from starting position only; used as a sanity reference.

Registered modules (15 total in module_adapters/_registry.py) divide into three evidence families. The production sampled-runtime manifest runs all 12 race-weekend and recent-history modules.

Residual-history modules emit zero means and large uncertainty (neutral_sigma=10.0); their training closures raise EventDataUnavailable. They exist as interface scaffolding only. See packets/evo_predictor.md for the full adapter file mapping.

Data Flow

PairBatch (from evo adapter)
  → network.py (pairwise means + uncertainty)
  → training.py (loss, backward, checkpoint)
  → field_solve.py (event-local pi field + covariance)
  → ModuleFieldResult (returned to evo fusion)

Known Limits

  • Trained on retro-delta supervision (Student-t NLL on BT posterior means), not direct rank likelihood or BCE pairwise outcomes
  • No persistent season recursion; events are independent
  • Depends on compound-prior availability in evo preprocessing (not internal to this package)
  • Target-season full-year compound priors are rejected by default (enforced at evo boundary)
  • Same-season training artifacts are a marked bootstrap compromise
  • Race-start modules do not distinguish opening-phase skill from incident exposure

Retro Architecture Notes

Retroactive phases are incremental: each phase conditions on the previous phase's observed outcome as its input order. predictive_pi − retroactive_pi is the phase-scoped residual and the primary supervision signal for missing predictive features. Retro fields depend on calibrated start-only baselines (params/retro_truth/start_only_baselines.json); baseline_fingerprint on PhaseObservation and config_fingerprint on RetroTruthSolution govern cache invalidation.

Retroactive fields capture realized weekend truth — execution, strategy, traffic, incidents, penalties. Not pure pace. Future modules needing pure pace require additional censoring.

Retro-delta supervision uses Student-t NLL, ν=4 (student_t_nu), on the mean head (term A). Sigma calibration adds a detached Student-t NLL (term B) weighted by lambda_sigma_nll (gold default 1.0); term B does not backprop into the mean head. Optional student_t_nu_sigma overrides ν for term B only when set. Post-hoc enable_sigma_calibration (alpha/beta fit) remains orthogonal to training-time sigma NLL. The legacy BCE/target_mode path was removed (#303). Full-eval diagnostics and gold reports (schema v6) persist r_over_sigma_p50/p90/p95/p99 and sigma_mean for ν sanity before per-task retuning.
