# Excursion Brief: Cognitive rules for building conceptual links

Cycle 2 (shotgun), `explore-memory-graph`. Human-initiated.

## The one named question

What deliberate cognitive techniques in the family of "ask why 5 times" exist for building conceptual links between ideas — and which of them could an agent run mechanically (as a repeatable rule, not vibes) to grow edges in a knowledge graph?

Context for the searcher: the project is designing an agent memory graph. The human's observation: humans use structured question-rituals (like Toyota's 5 Whys) to force connections they wouldn't otherwise draw. We want a catalog of such rituals as candidate EDGE-GENERATION rules — each one a prompt an agent could apply to a node to propose new typed links.

## Type

research

**Why this type:** the techniques exist in published traditions (root-cause analysis, creativity methods, learning science, note-taking practice); this is a survey with an eye to mechanizability.

## What "answered" looks like

A cited catalog of 8–15 techniques, each with: (1) the ritual and its origin (e.g. 5 Whys, Socratic questioning taxonomies, elaborative interrogation, Feynman technique, analogical structure-mapping, SCAMPER, TRIZ contradiction analysis, de Bono lateral-thinking provocations, Zettelkasten linking questions like "what does this remind me of / contradict?", concept-mapping's focus questions, Ishikawa categories, oblique strategies — go beyond this starter list); (2) what KIND of link it tends to produce (causal, analogical, contradictory, part-whole, generalization…); (3) a mechanizability verdict: could an agent apply it as a deterministic-ish rule to a node/pair of nodes, and what would one application cost? End with the 3–5 rules most promising as automated edge-builders and a note on which edge types they'd map to on a typed graph (supports / depends-on / constrained-by / explained-by …).

## Budget / stop conditions

- Budget: one focused research pass; report even if partial.
- Do NOT design the edge-generation subsystem; catalog and verdict only.
- **Scoped nulls:** "this technique resists mechanization" kills that technique under this framing, never the rule-driven-linking idea.

## Research excursion

- **Sources:** web + published method literature (root-cause analysis, creativity/ideation methods, learning science, PKM practice, analogy research). Name the origin of each technique.
- **Findings format:** each claim carries its source; keep the mechanizability verdicts clearly separated from the sourced descriptions (verdicts are the excursion's own judgment).
