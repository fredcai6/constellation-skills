# Euler #1 fixture

Seed repo for the scenario. Solve **Project Euler Problem #1** (sum of all
multiples of 3 or 5 below 1000) as a bounded constellation issue, with a solution
file and a passing `pytest` test. See `../task.md`.

This fixture is intentionally tiny and carries **no** `.py` files, so the eval's
process checks measure what the workflow produced, not what was seeded.
