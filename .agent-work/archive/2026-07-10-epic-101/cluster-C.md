### C — constellation-curator (new skill; measure-then-mend)

Human-only invoker, periodic cadence. Interface in deep-module terms — what the caller must know:

- **Trigger:** human runs it as periodic corpus maintenance ("run the curator"); never scheduled, never a code-change reaction, never agent-dispatched (untaken road: a report-only delegated mode, revivable later).
- **Invariant #1 — measure before mend:** every invocation begins by running `scripts/curate_corpus.py` over `skills/` — per-skill line/word counts vs soft budgets, description lint, invoker-tag presence, duplication-signature clusters, and TOC presence for >100-line references. **Lint scope is honest about decidability (T7):** the script checks only what is mechanical — pronoun-based person check, description length, presence of a when-to-use clause, presence/absence of an exclusion-clause marker, tag presence, size counts, signature-phrase clustering. Semantic judgments (is this clause a *procedure*? does the register *match* the tag?) are explicitly the human mend pass's job; the script may shortlist candidates but never claims those verdicts. Duplication-signature constants (shingle size etc.) are justified in code comments, not voodoo. The script emits `--json` machine output; a **drift-vs-baseline diff block is v2 (S7)** — built only when a second real run proves the diff is wanted.
- **Invariant #2 — flags, never gates:** enforced in the script (exit 0; findings are table rows), so the soft-budget rule cannot erode by prose drift. Distribution claims come from the table, never impressions.
- **Mend:** mechanical, verifiable-by-inspection fixes (description wording, TOCs, terminology, register touch-ups, boilerplate that re-accreted since last run) are applied in place. Git diff is the review gate. No engine checklist — the sweep is a fixed linear pass (triage precedent).
- **Route:** design decisions (move doctrine to `_shared`, re-scope a skill, kill a section) become Triage recommendations, never silent curator edits — triage's fix-now-vs-route ladder.
- **Portfolio duty — optional, decoupled (IF7/S2):** active only once the eval harness (E) exists; until then the curator has no eval-related duties and no dependency on E. When active: the report reviews scenario coverage and proposes new ones worth the time; it may flag "behavior-changing edit since last run: eval suggested" (flag, not gate). Curator's core — measure, mend, route — stands alone.
- **Outputs:** `CURATOR_REPORT.md` (findings, mends applied, routes, before/after measurement) + `--json` machine record. No durable-truth writes beyond the mends themselves.
- **Error modes:** a skill dir it cannot parse is reported as a row, not a crash; first run flags all skills for missing invoker tags (expected; it seeds the convention).

*Design-it-twice record:* full 3-candidate panel (minimal-interface / scout-analog / measurement-first) compared on depth, locality, seam placement, testability; human converged on the measure-then-mend hybrid. Comparison artifact: `excursions/c2-x1-curator-dit.md`. Pure candidates stand as untaken roads.
