# Research Handoff: Neighboring Graph-Substrate Projects

## One named question

Which active projects or architectural lineages are exploring shared graphed substrates for agent understanding, memory, coordination, or cognition, and what do their differing boundaries teach us about a system where recursively instantiated agents receive a home frame over a shared network?

## Context to preserve

- This is a personal experimentation framework for enabling ideas, not a product selection exercise.
- Near term, Markdown remains sufficient as the current-only map.
- Current reality, possibilities, and history are separate available information planes.
- Agents are instantiated recursively by other agents, as in Constellation skills. They are not persistent occupants of graph nodes.
- A home frame gives an instantiated agent starting context, local protocol, tools, and authority; it may traverse beyond the frame to understand connections.
- ActiveGraph has already been studied and is only a conceptual foil, not an adoption candidate. Do not center or recommend it.

## Required comparison

Select 5-8 genuinely distinct projects or architectural lineages, using current primary sources. Cover several of these families:

- GraphRAG or graph-based map/retrieval systems that compress source material into high-level navigable structure.
- Temporal knowledge or memory graphs for agents, especially current truth versus history.
- Cognitive hypergraph or executable-knowledge substrates.
- Multi-agent runtimes with dynamic identity, scoped context, delegation, or shared state.
- Blackboard/shared-workspace architectures where specialized reasoning processes operate over common representations.

For each, distinguish:

1. What the graph/shared substrate represents.
2. Whether agents are persistent entities, dynamically instantiated workers, workflow nodes, or external readers.
3. Where behavior lives: graph mechanics, runtime, agents, or a controller.
4. How context is selected and traversed.
5. How current truth, possibilities, and history are separated or mixed.
6. What authority/provenance model exists.
7. What lesson transfers here and what attractive trap should be avoided.

## Constraints

- Use official docs/repos and primary papers; current facts must be verified as of 2026-07-30.
- Do not install packages, run prototypes, modify source projects, or recommend adoption.
- Avoid treating workflow graphs such as LangGraph as equivalent to semantic substrate graphs; include one only if the contrast is instructive.
- Clearly mark inference versus sourced fact.
- Report tested and NOT tested scope.
