## Intent

Constellation's slice-by-slice execution is now reliable; this design makes the system **spend agent effort on the actual problem instead of the scaffolding, and learn to take a step back**. Concretely: (1) an immediate epic of small, evidence-backed fixes so agents never need to read engine internals, plans carry honest fixedness grades, prototypes buy information cheaply, and the existing 906-test suite actually gates merges; (2) shaped follow-on threads for the post-epic step-back phase (architectural refactor review + test honesty audit) and slice-wise planning; (3) recorded constraints and risks for the long-arc inversion where the engine runs the agents (#139). The unification is a viewpoint, not a premise — each piece stands on its own merit ("the grand unifying theory is a fiction"); synergies are taken where real.

For whom: every constellation agent (less wasted context, clearer recovery), and the human (plans that admit what is a guess; a system that can say "this made sense" with evidence).

Honest scope of the claims (post-critique): this epic **delivers step-lighter and seeds step-back** — the substantive step-back mechanisms (retrospect review, test-honesty audit, slice-wise planning) ship in Threads B/C, with S6's grading as the seed planted now. "Agents never need to read engine internals" is scoped to the **driving loop** (constructing the next verb from engine output); debugging and historical inspection remain legitimate reads. S4 and S10 ride the batch as evidence-backed paper-cuts surfaced by the same excursions — they serve reliability rather than either thrust, and are included on their own merit, not the banner's.

### S2 — Engine answerability interface (design-it-twice panel I1: recommendation)

**Panel record:** 3 candidates (minimal-interface, common-caller-first, ports-and-adapters), full texts at `dit-I1-*-RESULT.md`. Minimal and caller-first *independently converged* on the same shape — no new verbs; fatten the two surfaces the agent already stands at — which is strong evidence for it. Ports contributed internal structure and the conductor-future path.

**Recommendation (hybrid: caller-first surface, ports-lite internals, minimal discipline):**

1. **`current` becomes a complete gate briefing.** Full imperative verbatim (never elided), plus a conditions block for the active task: each open pre/postcondition as `id [state] kind — statement` one-liners (satisfied ones summarized, e.g. `2/3 met`). **Invariant INV-1 (completeness):** `current`'s output is a superset of every argument the caller's next verb needs — after `current`, the agent can construct `attest`/`advance`/`resume` without reading any file. **Invariant INV-2 (purity):** `current` reports *stored* condition flags only; it never live-runs a command check (state shows `pending`, never a speculative green) — the hottest read-only verb stays cheap and side-effect-free.
2. **Every state-caused REFUSED carries a recovery line naming the exact exit verb.** A shared state-derived helper maps (status, attempted verb) → sanctioned next command: `blocked` → `resume <id> --reason …` (and says no `unblock` verb exists); `complete` → `reopen`; unmet precondition → the `attest --which preconditions` command; unknown condition id on `attest` → enumerate the valid ids. Appends "Do not edit the JSON — use the engine." **Invariant INV-3 (recovery totality):** every (status, mutating-verb) refusal pair yields a non-generic recovery line; enumerated in a test. The recovery line is a separate channel from the five frozen rail strings (#145 measurement freeze untouched).
3. **Ports-lite internally:** the renderer is implemented as a pure state-projection helper (`state(cl) -> view dict` + `render_human(view)`), so the future conductor/hook JSON adapter (package D) is `json.dumps(view)` behind a flag added *when a consumer exists* — no public `--json`, no versioned contract, and no dual render path today. Ports' honest weakness (paying for D before D ships) is thereby deferred, not inherited; its structure (refusal-as-state, one place that knows what is knowable) is kept.
4. **Change is entirely inside `checklist_engine.py`** + one added clause in the check-failure rail pointing at `current`. Zero SKILL.md edits.
5. **Success instrument (F-T2):** ship `scripts/measure_overread.py` — a transcript scanner counting structural reads (spine/cycle JSON, engine source) per run — plus a fixed baseline corpus committed with the epic, so "scaffolding reads drop toward zero" is a reproducible command, not a fresh manual judgment. **INV-1's oracle (F-T1):** a small maintained verb→required-args map in the test suite; golden tests assert `current`'s output covers the map, so a new verb argument added without teaching `current` fails the test rather than passing by construction.

**Untaken roads (loud):** the `explain` verb (idea 2) — killed by both min and caller as a second surface the agent must remember to call at a moment away from where it stands; `show <id>` for non-active gates — unobserved demand in x1, promote `current`'s renderer later if it appears; public `--json` now — zero live consumers, and a reflexive `--json` dump would re-introduce the over-read it cures.

**Named risks:** wider `current` invites parsing-as-schema (mitigated: prose-shaped one-liners, not columns); the recovery table is a maintenance surface (guard: INV-3's enumeration test must stay exhaustive).

### S4 — Launcher resolve-at-install

Adopt x4's assessed recommendation: `install_constellation.py` probes the target host once (`py` → `python3` → `python`, first that answers `--version`) and stamps the resolved interpreter into installed SKILL.md copies + a sidecar read by engine-invoking commands. Repo source keeps `py` as the Windows-dev default. Untaken road: containerized/pinned runtimes (out of scope — installs must stay native).

### S5 — CI on the existing suite

GitHub Actions workflow on a Windows runner: `pytest tests/` (~30s, 906 tests) + coverage floor on the engine at **current-minus-1** — measure the baseline in-run with the stated command (`python -m coverage run --include="*/checklist_engine.py" -m pytest tests/test_checklist_engine.py -q && python -m coverage report`) and pin the floor from it (F-T7), rather than a slack hardcoded number. **Skip-guard (F-T8):** the git-integration tests `skipTest` when git is absent, so CI must assert zero unexpected skips (or fail on skip) — otherwise a runner without git goes green with the collector path unexercised. Pre-check before build: verify `windows-latest` provisions git-bash (x4 flagged as assumed, unverified). Design-it-twice skipped: conventional single-shape change; alternatives (other CI providers, Linux matrix) named as untaken roads — Linux leg becomes valuable only after S4 ships and is a natural follow-on there.

### S6 — Guess-grading schema (design-it-twice panel I2: recommendation)

**Panel record:** 3 candidates (minimal-interface, max-flexibility, common-caller-first), full texts at `dit-I2-*-RESULT.md`. All three independently converged on: one inline tag welded to the decision's line; the guess ledger is a *view* (grep/lint over tags), never a stored table; numeric confidence dies. The minimal candidate's pressure test — "no consumer branches on provenance kind" — was **answered** by caller-first: the executor's unsettle-routing branches on it (human-ruled → only the ruler unsettles; measured → re-measurable by better measurement; inherited → float to the owning tier). So a closed 3-kind provenance enum earns its place on settled decisions; everything richer died.

**Recommendation (hybrid: caller-first schema, min's executor default — "lint loud, execute safe"):**

1. **Markup:** one inline `@grade:` tag on the decision's own line, in the decision blocks that already exist (Pre-Rulings, Decision Anchors, `anchors.decision[]`, spec sections). Grammar: `@grade: <tier>[ /provenance][ · leans <ids>][ · settle: <experiment>]` with tier ∈ `settled | guess | placeholder`. One grammar across md and JSON; `@grade:` is the sole greppable anchor.
2. **Required floor:** tier always; `settle:` (the cheapest settling experiment, free text) required on every `guess` — a guess with no experiment is the ungrounded guess this schema exists to prevent; provenance (`/human | /measured | /inherited`) required on `settled` — settled-on-nothing is structurally unwritable. `leans <gate-ids>` optional sharpening (makes "load-bearing" a query and feeds rolling-wave's is-it-mine-now signal).
3. **Executor rules at a reality-contradiction (the tier is an index into an action, not a label):** `guess` → revise in place freely, run the settle experiment (or cheaper), log the ruling, regrade `settled/measured` — no reopen, no float; `settled/human` and `settled/inherited` → stop and float to the tier that owns it; `settled/measured` → re-measure, and a contradicting measurement IS license to revisit with the new provenance logged; `placeholder` → hard-stop only if the current slice leans on it (decide within latitude or float), otherwise leave for a later slice to crystallize.
4. **The fork, resolved as a hybrid:** at **pre-flight lint**, an ungraded decision inside a recognized decision block **FAILs loudly** (caller-first's honesty — new plans cannot ship ungraded, killing implicit everything-is-fixed at the moment grading costs one keystroke). At **execution time**, an ungraded decision reads as `settled` (min's safety — legacy/partial plans behave exactly like today's; the schema only ever *buys* freedom, never licenses silent divergence). Loudness lives in the linter, safety lives in the executor.
5. **The ledger is the linter — and S8 is folded in here (F-S5).** `grade_lint.py` generates the guess-ledger view on demand (load-bearing guesses, guesses missing `settle:`, ungraded decisions, settled inventory), scans for contradictions/TBD sections, and surfaces ALL objections as ONE batched question at the existing plan-approval checkpoint. One mechanism, one deliverable — ideas 7 and 29, independently confirmed by two candidates.
6. **Burden checkpoint (F-IF2):** the grading cost is asserted cheap, not measured. After the first epic that runs fully graded, review the actual authoring burden (tags written, settle-experiments named, lint objections raised vs. value received) and keep/trim the schema accordingly.
7. **Testability, honestly bucketed (F-T4):** the linter half is unit-testable now (fixture plans, seeded violations). The executor rules are **doctrine observed at first use** — the falsification arrives via the eval-on-change policy when a planning skill next changes (#136's scripted-principal seam), not before ship.

**Untaken roads (loud, from max-flexibility's own honest deaths):** numeric confidence (no consumer; idea 24 already culled); `depends-on` cascade edges (executor sees dependencies by reading the plan); `expires`/stale-by-default field (superseded by Thread C's regenerate-don't-reread; it was a hedge against C); structured settles-by (cost/owner/deadline sub-fields — the string survives); open provenance vocabulary (closed 3-kind enum + nothing); a stored ledger table (drift risk; the view is the ledger); a per-decision `revisit` override decoupling action from tier (max-flex's proposal — no demonstrated consumer beyond the tier defaults; revive if settled-but-cheap-to-revisit decisions appear in practice, per max-flex's own named simplification path).

**Named risks:** decisions written as loose prose outside recognized blocks escape the lint (convention-dependent hole — the linter's block list must grow with templates); cross-artifact `leans` (launch-order ruling leaned on by a commander gate) resolves only per-file for now — named as a future compile step, not silently promised; executor-behavior half of testability rides the eval-on-change seam (#136) — linter half is unit-testable today.

**Thread-C coupling, made explicit (F-IF5):** the `expires` field and per-file `leans` scoping were set aside *on the assumption* Thread C ships regenerate-don't-reread. They are **deferred pending C, not dead**: if C lands differently (plans persist across slices), `expires` revives and cross-artifact `leans` gets its compile step. C's design remains free to demand them back.
