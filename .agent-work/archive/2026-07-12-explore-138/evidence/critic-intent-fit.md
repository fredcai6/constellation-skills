| IF1 | intent-fit | MAJOR | The Getting-IN moment is the ONE moment the spec says has no runtime channel ("no runtime channel reaches an agent before its first engine call"), so skill wording is its sole defense. Yet 6 of the D1 targets get only the compressed one-sentence pointer-with-force, while the 1/3→3/3 result that justifies the whole clamp was measured on the full four-clause shape, not the compressed pointer. D1 itself asserts (without evidence) the pointer "repairs the measured defect," and D6's corpus-only arm plus D1's presence test only check that the sentence is *present*, never that the compressed form carries the four-clause force. The least-recoverable moment gets the least-proven treatment for the majority of skills. |  |  |
| IF2 | intent-fit | MAJOR | The corpus target is not pinned, so the Done criterion "no skill relying on wording proven not to fire" cannot be verified. D1's heading says "the nine stripped skills," but its own enumeration is implementer + reviewer (2) + commander-core (1, feeding two modes) + admiral + interrogator (2) + six pointer-only = 11–12 targets, not nine. The #101 finding it cites also said nine. A counter-doctrine whose scope denominator is internally inconsistent cannot demonstrate corpus-wide coverage, which is the pass's stated point ("ONE coherent counter-doctrine across the corpus"). |  |  |
| IF3 | intent-fit | MAJOR | Two of the six named cheap exits — wait-by-ending-turn and post-compaction amnesia (completion-theater/quit at the boundary) — are countered ONLY by D3 hooks. On any harness without hooks, two of the six named exits have ZERO counter, yet the rail is claimed "load-bearing on any harness." The spec draws the portability consequence for the hook *channel* but never for the *intent*: named exits go uncovered off-platform, contradicting "across the corpus." |  |  |
| IF4 | intent-fit | MAJOR | Fabrication / completion-theater on a *claimed-pass* step is unaddressed. The rail strings key on check-FAILURE ("fabricated evidence...forbidden") and near-terminal, but D2 appends the rail only to `current`, `advance`, `start`, and REFUSED — NOT to `attest`/`attach`, which is the exact chokepoint where an agent attaches fabricated evidence for a step it claims *succeeded*. The richest fabrication surface (assert a pass that didn't happen) receives no doctrine, while the intent names fabrication as a first-class cheap exit. |  |  |
