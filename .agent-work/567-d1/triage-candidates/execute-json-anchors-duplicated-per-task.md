# execute.json duplicates each gate's anchors block byte-identically across its triad

The cold plan critic's F12. A crew gate's `anchors` block (`structural`/`constraint`/`decision`/
`claim`/`evidence`) is carried on `gN-implement`, `gN-review` and `gN-integrate` alike, so a
four-gate plan holds nine redundant copies that must be hand-synchronised. Editing one copy of a
graded decision leaves the others silently disagreeing.

The critic's point lands hard in this lane specifically: duplicated instruction text that drifts is
the exact decay this epic's guard exists to stop, and the plan format reproduces it.

**Not acted on:** a triad-level or plan-level anchors block is an engine/schema change, outside a
lane's latitude.
