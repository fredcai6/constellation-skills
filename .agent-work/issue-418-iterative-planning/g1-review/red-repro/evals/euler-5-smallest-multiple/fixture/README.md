# Euler #5 fixture

Seed repo for the scenario. Solve **Project Euler Problem #5** (smallest positive
number evenly divisible by all integers 1 through 20) as a bounded constellation
issue, with a solution file and a passing `pytest` test. See `../task.md`.

This fixture is intentionally tiny and carries **no** `.py` files, so the eval's
process checks measure what the workflow produced, not what was seeded.
