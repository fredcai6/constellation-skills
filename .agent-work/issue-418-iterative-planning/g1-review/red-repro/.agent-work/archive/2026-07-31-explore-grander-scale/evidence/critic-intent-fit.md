# Critic findings — lens: intent-fit

Cold read of `DESIGN_SPEC.md` only. No exploration record, no ideas board, no cycle log. Disposition and Reason left empty by design — the critic does not self-triage.

| ID | Lens | Severity | Finding | Disposition | Reason |
|---|---|---|---|---|---|
| IF01 | intent-fit | BLOCKING | "Done" is defined as a lessons framework "in which observation is collated before reaction" — but Out of scope explicitly defers collation mechanization ("things that rhyme") as an implementation detail, and no testing pathway exercises collation at all. The B1 pathways test episode capture and one coherence sweep; neither shows that clusters are formed before a doctrine change is made. As written, "done" can be declared with a store full of episodes and reaction still happening one observation at a time — i.e. the exact behavior the Intent says the rework exists to end. Either collation needs a near-term acceptance test, or "collated before reacting" must be dropped from the done definition. | | |
| IF02 | intent-fit | BLOCKING | The Intent promises two things — "a shared knowledge substrate" in which "ideas acquire structure, interact, and become actionable," and a self-improving instruction system. Every Stratum B element serves only the second. B1 structures failure episodes, B2 structures doctrine loading, B3 structures map intake, B4 structures retrieval over the map. Nowhere in B does an *idea* (as opposed to a run defect or a code fact) acquire structure; the one surface where ideas apparently live is the ideas board, which is out of scope. The near-term stratum is a self-improving instruction system with no knowledge-substrate slice in it, so "done" tests only half the spec's own thesis and produces no evidence about the harder half. | | |
| IF03 | intent-fit | BLOCKING | The Intent's central mechanism is "agents are replaceable workers over durable state rather than carriers of ever-growing instructions." B2 attacks the second half (kernel plus just-in-time fragments) but *asserts* the first half as already true: "The run's artifacts carry accumulated state between steps, so late loading never means lost understanding." That claim is the load-bearing premise of the entire monolith-to-kernel break, and no testing pathway exercises it — projection determinism is tested, but not whether a kernel-only agent arriving at step N can execute correctly from artifacts alone. If run artifacts do not in fact carry the needed state, the break degrades every role while appearing to succeed on every listed test. The intent's durability claim is assumed, not built. | | |
| IF04 | intent-fit | MAJOR | Stratum A states the wider network "has no mandatory spine" and that frames declare structure only when purpose earns it. B2 makes the spine the universal selector for everything an agent loads ("the spine already knows which job is active, so it is the selector"). That deepens spine-dependence for the whole load path, so any future frame without a spine — a book, a philosophy region, the idea commons — has no defined way to project context to an agent. Stratum B is required to "not foreclose" Stratum A; this element points the load architecture at the one structure Stratum A says will often be absent. | | |
| IF05 | intent-fit | MAJOR | Purpose 3 — "a cross-project network where accumulated material forms unexpected ideas" — gets no near-term advancement, and B1 may actively foreclose it. The episode record's enumerated fields are run/spine/role-shaped (work-id, active gate, refusals, reopens, rework counts). Stratum A's "one assertion truth model" requires all truth claims to share mechanics. Nothing in the spec requires the episode record to be an assertion, or to be schema-compatible with one, yet B1 is the only durable accumulating store B builds. The most likely outcome is a Constellation-run-log silo that the assertion model must later be built alongside rather than over — a foreclosure the spec's own Stratum B rule prohibits. | | |
| IF06 | intent-fit | MAJOR | Purpose 2 requires maps that serve "both agent action and human understanding." Every near-term element serves agent action: the B3 success criterion is about agent orientation, the observability instrument is the projection manifest, the testing pathway measures agent load order. No B element produces or measures anything for human understanding. Worse, B2 removes an existing human-facing asset — today a role's single skill document is readable end to end by a person, and after the break no single artifact shows a role's full behavior; reconstructing it requires simulating the spine. Half of a stated purpose has no deliverable, no measurement, and a net regression. | | |
| IF07 | intent-fit | MAJOR | The two-bin rule (B0.4) says that when an item is mechanized "its prose version is deleted because the mechanism owns it." A validator encodes *what* is enforced but not *why it must exist* — and "why must this exist?" is precisely what Stratum A says a map may answer, and what the Intent's learning-and-understanding value depends on. B0.4 gives the rationale no home: it is not in the mechanism, it is deleted from prose, and B1 keeps episodes (observations) rather than rationale. For a project whose stated value is Tommy's learning, a corpus that systematically deletes the reasoning behind its hardest constraints works against the point. | | |
| IF08 | intent-fit | MAJOR | Purpose 4 is "genuine agent autonomy under human primacy," and Stratum A defines autonomy as delegated room to "traverse, propose, verify, and act inside explicit envelopes." Every B element moves in the primacy direction and none in the autonomy direction: B0.5 makes independent review a standing floor for anything that changes how anything works, B1 makes Curator findings proposals that "never directly mutate doctrine," the coherence sweep is *falsified* if findings mutate doctrine directly, and B3's success criterion is human-owned. Not one near-term element widens an envelope in which an agent acts without a proposal step. If the near-term stratum is the test of purpose 4, it can only ever return evidence about the primacy half. | | |
| IF09 | intent-fit | MAJOR | The Intent says the project "has no utility-based kill condition and does not need to outperform ordinary notes," while Testing pathways define falsification conditions for five of six items. The spec never states what a falsified pathway triggers. Under the Intent as written a falsified B3 apparently changes nothing, which makes the pathways decorative; if instead falsification can stop or rework a line of work, that is a utility gate the Intent disclaims. A reader deciding what to do when map-first runs regress correctness has no answer. | | |
| IF10 | intent-fit | MAJOR | B3 is the tracer for purpose 2's *honest* maps, but everything it measures is load order, not correctness. The manifest records "which map sections were loaded"; the pathway measures "whether the map found the seam before broad source crawling." A map that is confidently wrong and loaded first passes both. The only correctness signal offered — "whether targeted verification stayed correct" — has no threshold, no owner, and no falsification clause. The tracer therefore produces evidence about map *use* while the Intent's claim is about map *honesty*, and the spec treats these as the same measurement. | | |
| IF11 | intent-fit | MAJOR | B3's degraded mode says "a missing, stale, or contradictory map produces a reported degraded mode ... never a silent fallback." Missing is detectable. Stale and contradictory are not, and no detection mechanism is named anywhere in the spec — not in B3, not in B2's manifest, not in Cartographer (whose ontology is explicitly ruled out of scope for change). An agent cannot report a degraded mode it cannot detect, so the guarantee reduces to the missing case. Silent-stale is the specific failure that makes a map dishonest and the specific reason agents learn to distrust maps and crawl source anyway — the thing B3 exists to prevent is the thing it has no mechanism for. | | |
| IF12 | intent-fit | MAJOR | "Deletion is safe" is asserted as a property of done, but the evidence design is one deletion, one workflow run, with a falsification clause narrow enough to be near-unfalsifiable: worse-than-predicted impact is explicitly not failure, and failure requires that the tripwire "never surfaces it or never connects it back." Any tripwire that fires anywhere counts as the mechanism working. A single instance under those terms cannot distinguish "deletion is safe" from "we got lucky once," yet it is the sole standing pressure the spec offers against instruction growth — a pressure the Intent names as the reason the whole rework exists. | | |
| IF13 | intent-fit | MAJOR | The Intent grounds the project's value in Tommy's experience — "personal experimentation," "Tommy builds it himself as a learning playground," value is "ideas, learning, and enjoyment." The spec's entire delivery mode is the opposite: it is written to be cut into issues and executed by delegated agents, and nothing in it allocates any portion to Tommy's own hands or names which parts are his to build. A design optimized to produce the artifact efficiently can fully succeed on every listed test while delivering none of the stated value. If the value function is his experience, the build plan needs to say where his hands go. | | |
| IF14 | intent-fit | MAJOR | B0.5 says human review may be "mediated through conversation with an orchestrator, which counts as human review." Under the Intent's human primacy, review is the mechanism by which authority is actually exercised; routing it through an LLM conversation means the agent system determines what the human sees and how it is framed, and the human's signal is a response to the agent's own summary. Combined with "judgment scaled to consequence, not a universal gate" — where the scaling judgment is itself made by an agent — the review floor becomes self-certifying at exactly the moments consequence is highest. The Intent's primacy claim does not obviously sanction this. | | |
| IF15 | intent-fit | MAJOR | The Intent describes a playground whose value is enjoyment and learning. Stratum B adds five normative principles applying to every element, two-bin routing on every consolidated cluster, mandatory tripwire lessons for deletions and expected-improvement postings for additions, a proposal gate on Curator output, adversarial coherence sweeps on a cadence, an always-there review floor, and a design-it-twice obligation on three interfaces. Each is individually defensible; the aggregate is a governance regime substantially heavier than the system it governs. The spec never tests whether the ceremony load is compatible with the value it is meant to protect — and for a solo experimentation project, ceremony is the most common way enjoyment dies. | | |
| IF16 | intent-fit | MINOR | Purpose 5 — "revision-controllable graph history" — is named as one of five anchors and receives nothing in Stratum B beyond git tracking Markdown files, which was already true before this spec. No typed connections are created, no history model is built, and the append-only-events / current-vs-history separation lives entirely in Stratum A. B4 presumes "the map's typed connections" exist without any element creating them. Either the purpose needs a near-term slice or it should not be listed among the anchors the near-term stratum is supposed to advance. | | |
| IF17 | intent-fit | MINOR | B4 sits in Stratum B, which the spec defines as "what gets cut," yet the "done" definition names only the map-first support system and the lessons rework. B4 is also labeled an "earned increment, after B2/B3" with no stated earning trigger — while every other deferral in the spec (Neo4j, query language, telemetry) names observed pressure as its gate. Whether B4 is in scope for this cut, and what would earn it, is unresolved in a spec that is otherwise strict about exactly this. | | |
| IF18 | intent-fit | MINOR | The Confirmation block requires "Assumptions exercised" and "Assumptions accepted untested" to be recorded, but the spec nowhere enumerates its assumptions. Several are load-bearing and implicit — run artifacts carry sufficient state, the spine is always the right selector, rhyming episodes are reliably detectable by an LLM, manifests are sufficient observability, deterministic recipes can express real working sets. Without an assumptions list, the confirm gate is satisfiable by writing "none," and the mechanism meant to make untested reliance explicit records nothing. | | |
| IF19 | intent-fit | MINOR | The Intent disclaims a utility-based kill condition at the project level, while nearly every deferral in the spec is gated on utility at the increment level — "until observed pressure earns it" (backend, query language), "must earn its way in via a specific question" (telemetry), "revisit after local map use is proven" (federation). The two framings are never reconciled, so it is unclear whether a near-term element that proves useless is kept (project framing) or dropped (increment framing). | | |
