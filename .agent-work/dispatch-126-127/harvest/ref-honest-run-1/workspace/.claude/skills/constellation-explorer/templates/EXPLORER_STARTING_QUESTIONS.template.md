# Starting Questions — `explore-<topic>`

Seed questions for the **first** exploration cycle only. Ask them through the Interrogator: one at a time, with a recommended answer, appending follow-ups and skipping questions overcome by earlier answers. Later cycles do **not** reuse this list — they seed from the ideas board's open threads.

The point of these five is to surface the point before any solution is on the table. Answer them onto the board (the point / open threads), not into a spec.

1. **The itch** — what is actually bugging you? What made today the day you opened this? Describe the pain, not a solution.
2. **For whom** — who feels this, and who decides it's solved? (You? Another agent? A downstream skill? A future maintainer?)
3. **What does done feel like** — describe the world once this is handled. What can someone do then that they can't now?
4. **What already exists** — what in the repo, the ecosystem, or your own habits already partly addresses this? What did you try that fell short, and how?
5. **What would make this pointless** — what fact, if true, would mean this shouldn't be built at all? (The kill condition — name it now, test it early.)

Record each answer as a board entry. A strong answer to 5 can end the exploration before it starts — that is a win, not a waste.
