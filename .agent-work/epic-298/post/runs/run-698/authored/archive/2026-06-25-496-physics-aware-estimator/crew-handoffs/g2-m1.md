brake-ONSET transient too, with the anchor VALUE = a braking-frontier MODEL decel `a_b + b_b·v²`

This is the direct evolution of #498's plateau anchor.

## Concrete approach

  small robust `A + B·v²` fit. The model decel at speed v is `-(a_b + b_b·v²)` (sign: decel
  negative).
- Build an `AccelObs` (kind=3) over the FULL braking arc (not plateau-only): at each braking
  sample time, anchor value `a = model_decel(v_i)`, direction `(ex,ey)` = unit velocity heading
  from a cycle-1 smoother (`vx,vy = sm1.vel_at(t)`), `sigma` modest (try 0.5–2.0). You may start
  from `emit_accel_obs(...)` and replace the value/placement, or build `AccelObs` directly.
- Two-cycle structure (mirror `refine_trajectory`): cycle-1 Gaussian/Student-t fit → heading;
  cycle-2 `fit(..., accel_obs=onset_anchor)`. Project `a_long`.
- Your `VariantFn` returns the cycle-2 `a_long`.
