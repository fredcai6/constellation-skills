# G2 Spike M4 — Regime-gated process noise ("let the prior breathe")

(Read `g2-COMMON.md` in the same dir first — shared context, scoreboard seam, output rules.)

## Thesis
The blind smoothness prior fights the brake-onset step everywhere uniformly. M4 keeps the smoother
but INFLATES the jerk process variance ONLY inside brake-onset windows, so the prior stops
penalizing the physically-expected decel step exactly where a transient belongs — and stays tight
elsewhere (no global roughening, which would add ringing).

## Concrete approach
- The seam is `NSStintSmoother` (state-dependent per-step jerk process variance via a roughness
  schedule `_r_at(t)` / `build_roughness(...)`). Read how `build_roughness` + `NSStintSmoother`
  wire `r(t)` into the per-step Q (smoother.py ~lines 986–1185).
- Build a roughness/gating schedule `r(t)` that is HIGH (e.g. 3–10×) in a window around each
  brake-onset and ~1 elsewhere. Detect onsets from: the regime transition into `"straight_brake"`,
  and/or a threshold on the raw speed-derivative `|dv/dt|` (large negative = hard braking). A short
  lead-in window before the onset is the key (the prior must be loose BEFORE the step, not after).
- Your `VariantFn`: from `inp`, compute the gating `r(t)`, construct an `NSStintSmoother` with the
  same calibrated HPs as `inp.make_smoother` (read the HPs off a smoother it builds, or replicate
  the calibration), fit `(t,x,y,t,v)`, project `a_long`. NO kind=3 anchor (this is a pure
  process-noise mechanism — keep it clean to isolate the effect).
- Sweep the gate strength + window width enough to find a sensible setting; report the sweep.

## Why it's evolutionary
Extends the EXISTING NS roughness arm; touches only the process-noise schedule. The anchor is
unchanged → `decision:two_cycle_external_anchor_design` is NOT touched (state this).

## Watch for
- Over-inflating Q re-introduces ringing (the prior goes too loose → overshoot). The Monaco
  ringing metric is your guard: a gate that deepens Bahrain's knee but pushes Monaco ringing up is
  the failure mode to report.
- This is the cheapest mechanism; if it alone closes much of the Bahrain gap without Monaco
  regression, that is a strong PROMISING signal.
