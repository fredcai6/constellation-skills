## Field observations from #439 (walk-forward 2025 backtest) — compound_prior behavior in the wild

Building the leakage-free 2025 walk-forward backtest (#439) exercised the production `compound_prior` build/load path under conditions this issue cares about (thin support, identifiability). Two concrete data points:

**1. Thin-support hard non-convergence.** The walk-forward originally tried to rebuild an *as-of-N* 2025 prior from only the first N races (per-period, leakage-safe). At **N=6** the bounded-constrained effective-age solve did **not** converge — `scripts/fit_compound_prior` exited 1 with scipy `maximum number of function evaluations is exceeded` (after per-race baselining already logged the `Bounded constrained compound prior solve did not converge` warning). So beyond the β/γ degeneracy this issue documents, the production solver is also **fragile on thin support (~6 races): it hard-fails rather than returning an under-identified-but-usable fit.** Relevant to the §7.1/§7.5 "identification-limited, not refuted" framing — the failure mode at low N is a clean exit-1, not a degenerate artifact.

**2. Incomplete-coefficient committed artifacts.** The committed gold `params/gold/compound_prior/2018` declares `accepted_compounds=[C1..C5]` but only fitted β/γ for **C3/C4/C5** (C1/C2 had insufficient 2018 support). The strict runtime loader (`load_compound_prior_artifact`) requires a coefficient per accepted compound, so a same-season strict load of 2018 raises `parameter_means lacks 'beta_C1'`. The production gold path avoids this only because it resolves **cross-season** (`allow_same_season_compound_prior=false` → pooled prior-season artifact).

**Decision taken in #439 (route around, not investigate — investigation is *this* issue's scope):** the backtest uses **cross-season compound priors throughout** (matching the promoted gold) instead of per-period same-season rebuilds. Rationale: compound normalization is a second-order signal in that backtest, the dominant signal is in-season model retraining, and "fix the fragile/degenerate solver" belongs here, not in #439. A per-period same-season compound rebuild remains a clean follow-up gated on (a) thin-support solver robustness and (b) loader tolerance for incomplete-coefficient artifacts.

Logging as a field observation only — **#382 stays closed**; noting it here so the next person reviving the deg-identification work has the thin-N failure signature and the incomplete-artifact gotcha in hand.
