# Critic Findings — Simplicity / YAGNI Lens

| ID | Lens | Severity | Finding | Disposition | Reason |
|---|---|---|---|---|---|
| SY1 | simplicity | MAJOR | The two-track structure (D2 weekly loop + D3 five-item point-engine track, "run concurrently where capacity allows") re-creates the shape of the explicitly-rejected "everything by Belgium" approach under a new name. The exploration record itself admits this ("partially revived when the human removed the merge freeze; remaining difference is sequencing discipline only"). Sequencing discipline alone doesn't reduce the number of simultaneous workstreams (housekeeping, decomposition study, DNF channel, #513/#450, ephemeris/#589, RegulationEra #483) competing for the same 7-day runway as the one hard deadline (Belgium). If none of Track 2 is allowed to affect Belgium (D2 says the current gold predicts Belgium unless retrain is strictly better), the case for running five Track-2 items concurrently with the shakedown, rather than strictly after it, is not made anywhere in the spec. |  |  |
| SY2 | simplicity | MAJOR | D3 item 1 (league decomposition study: parse five workbooks, compute walk-forward placements, decompose the edge into channels) is scheduled first because it's "cheap; steers the rest" — but D3 also says items run "concurrently where capacity allows," so nothing is actually gated on its output before it finishes. The exploration record already names the candidate channels (top-5 bingo capture, midfield ordering, DNF avoidance, quali-day information) without a parser. If item 2 (DNF hazard) is going to be built regardless — it's clearly needed independent of channel ranking — the decomposition study's "steers the rest" justification is weaker than its cost (parsing 5 Excel workbooks, reproducing three historical totals as validation) suggests. Candidate for descoping to a rough manual estimate, or deferring past Belgium. |  |  |
| SY3 | simplicity | MINOR | The mid-week gold retrain including 2026 R1–R9 is explicitly declared "informational" and non-gating for Belgium. An artifact that by the spec's own design cannot change the week's one real decision (what to submit for Belgium) is decorative for this push, however cheap it is to run (stated as "overnight"). If it's truly free (unattended compute), low cost; if it consumes any engineer/agent attention to interpret results this week, that attention has no payoff until later. Worth stating explicitly why it can't just be deferred to next week's cycle rather than run informationally now. |  |  |
| SY4 | simplicity | MAJOR | D4 asks every model change to report a scoreboard spanning: simulated league placement (north star), fantasy pts/race on 2025-holdout, fantasy pts/race on 2026-so-far, existing Brier/sign-accuracy, and (after each real race) the weekly gap-to-front number. That's up to five parallel metrics/reporting surfaces to stand up in the same week as the shakedown. The spec names simulated league placement as north star — the other four read as "might as well report while we're at it" rather than decision-relevant this week. Building the full reporting harness now, rather than shipping placement-only and layering the rest post-Belgium, is scope inflation dressed as measurement rigor. |  |  |
| SY5 | simplicity | MINOR | D5 housekeeping (rescue 17 scripts, decide on the 2GB DB, triage the 63-commit branch) is declared "day 1–2, non-blocking." If it's genuinely non-blocking, the spec doesn't explain why it must be front-loaded into the first two days of the one week that has a hard, dated deliverable (Belgium, 7 days out) rather than deferred to whenever Track 2 has slack. Placing non-blocking cleanup at the start of the tightest week in the roadmap is exactly the "displacement activity a week before a race" pattern the assigned lens asks about. |  |  |
| SY6 | simplicity | MAJOR | D3 item 4 (ephemeris regeneration + #589 backfill verification) carries two bundled justifications: "hygiene" and "unlocks explainer-grade physics content." The second justification isn't load-bearing this week — the Belgium race-preview explainer (D2) draws on the evo model's own evidence channels, since #513→#450 (the physics-into-predictor bridge) is unbuilt and explicitly not gating Belgium. Doing ephemeris-regen now produces explainer content nothing consumes yet; the item should be justified on hygiene alone (and possibly deferred, since #589 already sits on its own D-series debt track per Out of Scope), not padded with a benefit that can't be realized this cycle. |  |  |
| SY7 | simplicity | MAJOR | D3 item 3 (#513 FP-session physics fits → #450 A/B) commits real capacity mid-sprint to a channel whose precedent (C1–C3) returned CONTEXTUAL/weak verdicts three times running (circuit-conditional, fine-margin, not a clean car axis) — and the item is explicitly non-gating for Belgium. Meanwhile DNF/reliability hazard (item 2) is a genuinely untried, discrete bet more directly tied to a named scoring mechanic (bingo/delta-sum penalties for finishers who don't finish). The spec doesn't argue why #513/#450 capacity is better spent now versus doubling down on the DNF channel first and picking up #513 only if decomposition (item 1) shows quali-day information is actually where the missing 7.5 pts/race live. |  |  |
| SY8 | simplicity | MAJOR | The Testing pathways section makes the weekly loop's falsification condition "the command cannot produce a submittable list + explainer from Friday FP data before quali lock" — bundling the explainer (and, via D4, implicitly the scoreboard) into the same pass/fail gate as the ranked top-10 list. Only the list is strictly necessary for "Tommy can submit picks on an inattentive week" (Intent, item 1). The explainer (item 2) and scoreboard (item 3) are separately-described "done" criteria that don't need to exist for the shakedown to prove the core loop works. Folding all three into one gate means a working prediction pipeline with an unfinished explainer reads as a failed shakedown, which overstates what actually needs to ship this week. |  |  |
| SY9 | simplicity | MINOR | D1 (mission consolidation into AGENTS.md/CLAUDE.md, correcting the stale 24-param-scorer description) is legitimate documentation debt — verified: CLAUDE.md's current evo_predictor Architecture section still describes the 24-parameter vector and scorer.py/ranker.py as if they were the live path, which the exploration record says has been superseded by a 3-stage sampled simulator over 12 neural latent-power modules. But it has zero effect on points-per-race and no dependency link to Belgium. Sequencing it as day-1 work (Sequencing table) means it competes for attention in the same window as the shakedown, for a task that could land any week without consequence. |  |  |
| SY10 | simplicity | MAJOR | Three separate A/B harnesses are stood up in the same week: DNF hazard shape (item 2, "decided at cut time by A/B"), #513/#450 vs the quali ceiling (item 3, "the existing honest A/B harness"), and RegulationEra train-vs-recalibrate-on-2026 (item 5, "decided by A/B inside the gold cycle"). Each A/B needs its own held-out evaluation design, calibration checks, and interpretation. Running three concurrently, alongside a decomposition study and a shakedown, is a research programme's worth of parallel experimentation for a push whose actual deliverable this week is one dated prediction. |  |  |
| SY11 | simplicity | MINOR | D5's "deliberate keep/exclude decision on the 2GB f1_data_2023.db telemetry swell before any commit touches it" folds ambient repo-hygiene debt into this push's scope. Verified: the file is ~1.95 GB and DB files are already committed routinely (current git status shows f1_data_2022/2023/2024/2025/2026.db all modified as ordinary churn), so this decision is really about a pre-existing repo-wide practice, not something this push's Belgium deadline created or needs resolved to hit. Riding it along under D5 without saying so understates that it's independent debt. |  |  |
