## Out-of-scope observations

1. **Lateral A0=2.64 is a cross-circuit pool artifact.** Monaco requires ~4–5 g_lat in fast corners. The pool of 22 circuits averages the lateral grip across very different track types; the Monaco apex-speed signal is diluted by high-speed circuits where A0 is lower. This is the proximate cause of the (b) under-call and would recur on any circuit with a large lateral demand cluster. Route to the decide-fix checkpoint and Epic C1 fix planning.

2. **Braking-zone cap mismatch has a secondary geometry component.** At the Massenet zone (~640–710m), the ribbon curvature already captures the upcoming corner inflection, so the sim starts outputting corner caps (14–30 m/s) while the real car is still braking from 70+ m/s into that corner. This is NOT a progress-fraction registration artifact (true-distance shows identical values); it is a ribbon geometry issue — the pooled ribbon curvature represents the arc, not the braking initiation point. A corner-entry landmark alignment (matching the real braking-initiation to the sim's corner entry) would fix this zone but is a separate concern from the lateral A0 under-call in true fast-corner zones (tunnel).

3. **Sim overall speed ceiling under-called.** v_ideal_max = 62.1 m/s vs v_real_max = 80.3 m/s (VER's best sector 1 speed). This 23% global under-call means the straight-line regime denominator is also shrunk, though the straight-line U is not reported as anomalous in the #518 context.
