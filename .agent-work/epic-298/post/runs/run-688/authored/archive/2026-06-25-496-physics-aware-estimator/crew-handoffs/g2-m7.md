# G2 Spike M7 — Model-aware raw-speed denoise → kind=3 anchor

(Read `g2-COMMON.md` in the same dir first — shared context, scoreboard seam, output rules.)

## Thesis
The raw speed sensor already SHOWS the real 5.3 g (it is the un-biased truth). The problem is only
that the 2D position-smoothness prior overrides it in transients. M7 promotes the raw speed channel
to primary longitudinal truth: denoise it with a 1D edge-preserving filter (total-variation /
physics-residual) that PERMITS the sharp brake-onset step, derive `a_long` from the denoised speed,
and feed THAT as a high-confidence kind=3 anchor across the full braking arc. Geometry still comes
from the 2D smoother. This is the cleanest path to RETIRING `clean_longitudinal_from_raw` (the
current raw-speed band-aid) by routing it through a principled filter.

## Concrete approach
- Start from the raw speed → `a_long_raw` already available (`inp.a_long_raw`, from
  `clean_longitudinal_from_raw`). Denoise the SPEED (or directly `a_long_raw`) with a 1D
  total-variation / Huber-edge filter: TV denoising preserves the onset edge while killing
  high-frequency sensor noise (try `scipy`-based TV or an L1-trend / Huber smoother; small,
  self-contained). The point: the denoised `a_long` keeps the sharp knee but is not jagged.
- Build an `AccelObs` (kind=3) over the braking arc with value = denoised-raw `a_long`, heading from
  a cycle-1 smoother, modest `sigma`. Two-cycle structure like `refine_trajectory`. Project `a_long`.
- Your `VariantFn` returns the cycle-2 `a_long`.

## INVARIANT EXTENSION — flag explicitly
M7's anchor is DERIVED FROM RAW SPEED (denoised), never from the smoothed trajectory — so it stays
within "external & un-biased" in spirit. But it changes placement (full braking arc, not
plateau-only) and applies a denoise transform. State: the denoise is edge-PRESERVING (does not
invent the step), and is applied to raw only. This is the most invariant-faithful of the anchor
spikes — make the case.

## Watch for
- TV denoise hyperparameter (regularization λ): too strong → flattens the knee (defeats the
  purpose); too weak → passes sensor noise. Report the λ sweep and pick by the scoreboard.
- Bahrain is the prime target (the raw shows −52; if your denoised anchor preserves it AND the
  smoother accepts it, the knee should deepen markedly). Monaco: confirm denoised raw is clean in
  the non-throttle region (the raw ceiling there is ~5.6; your anchor should not inject ringing).
