## The one thing this wave is for

Every issue in wave 3 was **a guard that could not register its own failure**, and #467's **DC6 is
that defect stated as a deliberate design cost**:

> *"a refusal is self-enforcing and self-recording, while an instruction is satisfied or ignored
> with identical traces. Converting HARD from a refusal into a sentence removes the only mechanism
> that could register an agent ignoring it."*

So the single most important thing you can get wrong here is to **ship DC1-DC3, watch the suite go
green, and call it done.** A green suite is exactly what the broken world produces for DC6. The
replacement signal must be **mechanical** — #467 names the shape: *the engine can see whether a
handoff artifact appeared before the next advance at an over-threshold gate.* Build that, and prove
it fails when a handoff is absent.

**Mutation-test every guard you ship.** Break the branch the test defends and confirm the test goes
**red**. A wave-2 reviewer invented this unprompted and it has caught real defects in every wave
since. A test that passes on both sides of its own fix is this epic's central defect, and shipping
one inside the fix *for* that defect would be the funniest possible outcome.

**No absence is evidence.** #467 states it and it is not decoration: a silent governor and a
governor with headroom are indistinguishable. **Assert a reading exists before any claim about trip
behaviour**, and if your run observes no trip, say which of the two you observed. This is not
hypothetical — see the field data below.
